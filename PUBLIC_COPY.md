# Public-facing copy: Short, medium, long

Tagline (15 chars):
Forward Thinking Parents

One-liner (30–60 chars):
Shared custody calendar and swap requests for separated parents.

Elevator pitch (30–50 words):
Forward Thinking Parents helps separated guardians coordinate custody and schedules without messy back-and-forth messages. Create a family workspace, add children, and share a clear custody calendar — with simple swap requests and reminders so everyone knows where the kids should be.

Hero CTA ideas
- Primary: Try the demo — no signup
- Secondary: Learn how it works (tour)

Short FAQs
- Is my data private? — Only invited family members can see family data; we use Supabase RLS and follow security best practices (see Security Summary).
- How do I invite the other parent? — Create a family, send an invite link from the family page.

Suggested landing page sections
- Problem statement + hero
- Key benefits (clear schedule, low-friction swaps, better co-parenting)
- Demo CTA and screenshots
- Security & privacy blurb
- Testimonials / early-user notes (once available)
